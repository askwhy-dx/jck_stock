# bowl3-chart — 밥그릇3 설명 이미지

판정 기준 SSOT = `jck_stock/screen_bowl3_quality.py`(docstring) · 탭 운용 = `jck_stock/CLAUDE.md` 의 `build_bowl3_tab.js` 행.
스크립트가 스캐너 함수(`find_pullbacks`)를 그대로 불러 구간을 다시 계산하므로 기준이 바뀌어도 그림이 따라간다.

## 순서

모든 명령은 `jck_stock` 폴더에서. 출력 PNG 는 세션 scratchpad 에 둔다.

1. **대상 정하기**
   - 종목을 짚었으면 그 종목(코드 6자리 또는 KRX 종목명).
   - "대시보드 종목 중 제일 좋은" → `data/bowl3_state.json` 의 `managed` 종목 전부를 그려 비교한 뒤 하나를 고른다(근거: 장기선 대비 위치·수급·이후 흐름).
2. **1차 실행 — 사실 뽑기**
   `python -X utf8 .claude/skills/bowl3-chart/scripts/bowl3_chart.py <코드|이름> --out <scratchpad>/<이름>_bowl3.png`
   - 마지막 줄 = 사실 JSON. 약 30초(KRX 캐시 전체 로드).
   - `밥그릇3 눌림 양봉 신호 없음` 이면 **밥그릇3 종목이 아니다** — 억지로 그리지 말고 그렇게 답한다. 신호가 여럿이면 최신 것, 특정 신호는 `--pull YYYYMMDD`.
3. **notes.json 쓰기** — Write 도구로(heredoc 금지: `\n` 이 먹힌다).
   ```json
   {"title": "종목(코드) — 한 줄 요지", "read": ["줄\n  이어지는 줄", "..."], "warn": ["...", "..."]}
   ```
   - `read` 3~4개(신호 이후 흐름 · 현재 위치 · 매수 구간과 종가 거리), `warn` 2~4개(약점·미조회·가격 계획 기준일).
   - **숫자는 사실 JSON 값만** 쓴다. 없는 값(미조회)을 추정하지 않는다.
   - 한 줄 22자 안팎, 넘으면 `\n` + 공백 2칸. 맑은 고딕에 없는 `−` `✔` `⚠` 는 쓰지 않는다(스크립트가 바꾸긴 한다).
4. **2차 실행** — 같은 명령에 `--notes <notes.json>`. 그다음 PNG 를 **Read 로 직접 보고** 상자 겹침·잘림을 확인한다. 겹치면 스크립트 `note(...)` 의 후보 오프셋을 고친다.
   - **기본 = 시나리오 포함**(26-11-06 사용자 확정 · 끄려면 `--no-scen`) — 오른쪽에 앞으로 20거래일 A 체결→목표 / B 미체결 상승(목표 위 종가 = 탭 삭제) / C 체결 뒤 손절 예시 경로를 `bowl3_state.json` 가격 계획으로 그리고, 오른쪽 칸에 「앞으로 (탭 규칙)」 4줄이 들어간다. 이때 notes `read` 는 3줄 이하로 줄인다(아래 「주의할 점」 상자와 겹침). 경로는 예시이며 확률이 아니다.
5. **답하기** — PNG 경로(절대경로) + ①~⑥ 순서로 짧게 풀어 쓴다. 조건 X·미조회는 숨기지 않는다.

## 사실 JSON 읽는 법

| 키 | 뜻 |
|---|---|
| `krx_last` · `last` | KRX 캐시 마지막 봉. 장중·15:30 전이면 **전일 확정 종가**다 — "오늘 종가"라고 쓰지 않는다 |
| `last.vs_line_pct` | 종가 ÷ 장기선(max MA112·224) − 1 |
| `flow_5d` · `negative` · `fin` | 최신 `data/bowl3_quality_*.json` 에서 가져옴. 없으면 수급만 백테스트 캐시, 나머지 `null` = 미조회 |
| `plan` | `data/bowl3_state.json` 의 1·2·3차·손절·목표(탭에 들어온 날 고정). `null` 이면 탭에 없는 종목 — 가격선 안 그림 |
| `after_high` | 눌림일 이후 최고가 |
