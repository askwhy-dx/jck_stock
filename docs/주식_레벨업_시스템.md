# 📈 주식 레벨업 통합 시스템

> 레벨별 미션을 달성하면서 시드(주식 자산)를 안전하게 키우는 자기검증 프레임워크.
> 거래일지·월별스냅샷·KPI·레벨 체크리스트·대시보드를 **하나의 Google Sheet에 통합**해
> 손으로 옮겨 적을 필요 없이 자동으로 진급/유지/강등을 판정합니다.

---

## 🎯 핵심 설계 원칙

1. **단일 입력 원칙(Single Source of Truth)** — 입력은 두 곳뿐.
   - `01_거래일지` : 매 거래 종결 시 한 행
   - `02_월별스냅샷` : 매월 말 잔고/입금 한 행
2. **자동 파이프라인** — 입력 → KPI → 체크리스트 → 대시보드까지 수식만으로 흐름.
3. **AND/OR 판정** — 진급 조건은 AND, 강등 트리거는 OR. 한 개라도 빠지거나 발동되면 즉시 결과 변동.
4. **체급 적응기** — 시드 5배 확장 시 3~6개월 체급 적응기 통과 필수(심리 비용 비선형성 대응).
5. **자립 지수** — 누적 수익 ÷ (수익 + 입금) × 100. Level 4부터 30% / Level 5부터 60% 필수.

## 📝 일상 운영 루틴

### 매 거래 종결 직후 (2분)
1. Google Sheet → `01_거래일지` 다음 빈 행
2. 매수일·매도일·종목명·매수가·매도가·수량 입력
3. 손절가 도달? / 손절 준수? / 원칙 위반? (Y/N) 입력
4. **끝.** 매수금액·매도금액·손익·수익률은 자동 계산

### 매월 말 (1분)
1. `02_월별스냅샷` 다음 빈 행
2. 연월(YYYY-MM), 기말 잔고(만원), 당월 입금(만원)
3. **끝.** 누적·수익률·MDD·고점 자동 계산 → KPI/체크리스트/대시보드 전부 갱신

### 주 1회 점검 (5분)
- `05_대시보드`에서 5개 레벨 판정 확인
- 노란불(🟡)·빨간불(🔻)이 들어왔다면 해당 시트 열어 미달 항목 확인
- `04_로드맵_L0_L5`에서 강등 트리거 항목 재학습

## 🎨 분석 대시보드 ↔ 레벨 시스템 연동

`분석_대시보드.html`의 **🏁 종료 탭**에 다음 두 가지가 추가되었습니다.

1. **상단 요약 바**: 누적 실현손익 + 현재 레벨 + 통합 시트 바로가기
2. **📊 레벨 시스템 진행 현황 카드**:
   - 핵심 KPI 9개 스냅샷 (현재 레벨·운영 기간·손절 준수율·원칙 위반율·MDD·연 Floor·자립 지수·손익비·실거래 횟수)
   - 현재 Level 1 → Level 2 도전 중. L1→L2 진급 체크리스트 5개 항목 중 4/5 충족 (운영 기간 ≥6개월만 미달, 현재 5개월차)
   - 다음 단계 미션 (운영 기간 +1개월 → L1 6개월 조건 충족 시 L2 진입)

종결 거래가 추가될 때마다 통합 시트의 KPI가 갱신되고, 대시보드 빌드 시 이 값들이 종료 탭에 반영됩니다. **종결 거래만 들어가면 → 시트 KPI 갱신 → 대시보드 종료탭 자동 변동**의 루프입니다.

## ⚠️ 주의 사항

- 본 시스템은 **자기 검증 프레임워크**이지 투자 권유가 아닙니다.
- 모든 수치(기간/MDD/Floor/자립 지수 목표)는 일반적 권장 기준이며, 본인의 소득·생활비·세금·시장 환경·리스크 허용도에 맞게 조정하세요.
- Y/N은 반드시 대문자, 잔고는 만원 단위, 음수 지표는 - 부호 포함.
- 모든 진급 조건은 AND, 모든 강등 트리거는 OR. 한 개라도 빠지면 진급 불가, 한 개라도 발동되면 강등.
- **R6 총 손실 -30% 한도** 초과 시 시스템 중단 + 90일 관망 + 2단계 강등.

## 📚 자립 지수 공식 (Autonomy Index)

```
자립 지수 = 누적 수익 ÷ (누적 수익 + 누적 입금) × 100  (%)
```

| 구간 | 해석 |
|------|------|
| 0~30% | 월급으로 밀어올린 시드. 실력 검증 안 됨 |
| 30~60% | 실력과 자금이 병행 성장 (Level 4 최소) |
| 60%+ | 수익 주도 성장 (Level 5 목표) |

- 누적 수익 < 0 → '손실 의존도 경고'. 입금으로 손실 메꾸기 패턴 감지 시 Level 0 강제 복귀.
