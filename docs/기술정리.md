- `POST https://data-dbg.krx.co.kr/svc/apis/sto/{stk_bydd_trd|ksq_bydd_trd|stk_isu_base_info}` · body `{"basDd":"YYYYMMDD"}` · 헤더 `AUTH_KEY`.
- 응답 키(`OutBlock_1`/`output`/`data`) 자동 폴백, 필드를 snake_case 로 정규화(`code·name·market·open·high·low·close·volume·trading_value·market_cap·shares`, 원본은 `_raw`).
- 429 는 지수 백오프 3회. 전일 데이터는 ~08시 공개.

### 4.2 OHLCV 캐시 `data/krx_ohlcv_cache/{YYYYMMDD}_{KOSPI|KOSDAQ}.json`
- 구조 `{bas_dd, market, rows:[...]}`. 영업일당 시장별 1파일, 받으면 재호출 없음.
- 연속 구간 **2023-01 ~ 현재**(2026-08-20 `fetch_krx_history.py` 로 930일 확장).
- ⚠️ **휴장일 파일은 `rows: []`** — 거래일 판정·「최신 파일」 선택은 파일 존재가 아니라 **행수**로. 빈 파일을 최신으로 잡으면 우량주 가격위치가 전 종목 null → 등급 일괄 하향.
- KRX 종가는 액면분할 미보정 → 분할 종목 가짜 돌파 가능.

### 4.3 DART OpenAPI (`dart_openapi.py`)
- `list.json`(공시검색) · `fnlttSinglAcntAll.json`(재무 · 1콜 3개년) · `corpCode.xml`.
- 캐시 `data/dart_cache/`: 공시 24h · 재무 7일 · corp_code 7일.

### 4.4 토스 (`toss_capture.py`)
- Playwright 세션 `toss_session/`. 만료 시 `--login`.
- 종목 URL 코드는 A-prefix 우선 · bare 폴백(`_candidate_codes`).
- 등락률 부호가 탈락해 급락을 상승으로 오판한 버그 이력 → 이중 보정.

### 4.5 기타
- 네이버 테마 모바일 API (`data/naver_theme_map.json` 7일 캐시) — 테마 탭 원천이었으나 현재는 반도체 분류표(5.5)가 테마를 정한다.

## 10. 작업 규칙 · 함정 모음 (깨지면 조용히 틀리는 것)

### 10.1 규칙
- 업로드는 `node upload_dashboard.js` 로만. 실행 전 `commitMsg` 를 한 줄로 교체(백슬래시 금지) → `node --check`. `git init` 금지. **이미지 업로드 영구 금지**.
- 발행·새로고침은 사용자가 시켰을 때만. 에이전트 기본 범위는 「수정」까지.

- 대시보드는 공개 — 회사·개인 데이터 금지.
- 완료 이력은 `docs/CHANGELOG.md` 에만(맨 위 추가). `CLAUDE.md` 는 현재 상태·규칙만.

### 7.5 활성 0종 동기화와 실패 전달 (2026-10-29)
`toss_capture.parse_holdings_from_md`는 §6의 `**활성**:` 줄만 읽는다. 빈 줄은 정상적인 0종(`[]`), 섹션·줄 부재는 파싱 실패(`None`)다. 빈 활성 줄에서 과거 이력 코드로 대체하지 않는다. `resolve_stocks`는 정상적인 0종을 `stocks.json`에 저장하고 밥그릇3 관찰 종목만 별도로 더한다. 일반 호출의 빈 목록 덮어쓰기 차단·절반 미만 축소 가드는 유지한다.
`run_daily_dante.bat`의 휴장·API 수집·스캐너·분석·Slack 단계는 원래 명령의 종료코드를 로그 출력 전에 저장한다. 분석 실패 시 발행을 중단하고 일일 요약에 실패 원인을 기록하며 배치도 exit 1을 반환한다.
