## 0. 한눈에 — 닫힌 학습 루프

```
[교재]   build_lessons.js   → lessons.json            (종결 시 수동)
   │
[1b] recall_similar.js      → recall_latest.json       (매 회차 · 유사 패턴 회상)
   │
[2]  claude_dante_analyze   → 판정 + predictions.jsonl  (매 회차 · 회상+교훈 반영 판정 후 원장 append)
   │
[2b] score_predictions.js   → scorecard.json            (매 회차 · 진입 +10거래일 채점)
   │
[토 08:00] reflect_agent.js → proposals.json            (주 1회 · 회고 → 개선안 제안)
   │
[사람]   터미널 승인         → 룰·파라미터·교재 반영      → 다음 판정 개선 (진화)
```

- **학습한다** = 과거 거래의 결과·교훈이 다음 판정에 자동으로 반영된다.
- **진화한다** = 거래가 쌓일수록 ① 회상 풀이 커지고 ② 검증된 교훈이 룰로 승격되어, 판정 품질이 *측정 가능하게* 좋아진다.

### 2-4. 채점 — `scorecard.json`

진입 +10거래일 뒤 KRX 종가로 판정의 적중/수익률을 매김.

- **현재 실데이터: 채점 0 / 대기 71** (윈도우 미경과). 6/2부터 한 배치씩 채워짐.

**채점 메커니즘 데모 (`--simulate`, 과거 기준일 20260428 + 실제 KRX forward 10거래일)** — 판정은 합성(랜덤 배정)이라 *배관 검증용*이며 숫자 자체엔 의미 없음:

```
채점 40/40건 — 적중률 52.5% · 평균 -5.41%
  🟢 매수 준비   적중   0% (n=10)   ← 하락장 구간 + 합성판정 인공물
  🚫 손절 검토   적중  80% (n=10)
  🟡 보유 유지   적중  30% (n=10)
  ⏸ 보류        적중 100% (n=10)
  거래량: 위축 64% / 보통 47% / 급증 44%
```

> 이 데모가 증명하는 것: 거래일 카운트(+10, 휴장 자동 제외)·시장 자동판별·판정별/조건별 집계가 정상 작동. 실제 신호는 6/2 이후 *실판정*이 채점되어야 나온다.

**P-Score 등급 배지 (우선순위 색)** — 점수 4축(영향40·근거30·재발15·검증15) 합산 → 등급 산정. 콘솔·Slack 동일 색 사용:

| 색 | 등급 | 조건 | 의미 |
|---|---|---|---|

## 3. "진화" — 제안 → 승인 → 반영

```
reflect_agent → proposals.json (pending_review)
        │
   터미널에서 사람이 검토 ("2번 승인")
        │
   승인된 것만 반영:
     · lessons.json (교훈 보강)        → 다음 회상에 끼어듦
     · §단테 룰 / strategy_params.json → 다음 판정 기준 변경
        │
   변경 후 채점(scorecard)이 사후 검증 → 개선됐는지 다음 회고가 확인
```

- AI는 **제안만**, 결정은 **사람**. 모든 반영은 기록(롤백 가능).
- 표본 부족 시(최소 n 미달) 제안 자체를 보류 → 노이즈 학습 차단.
- 기법(밥그릇·파동 정의)은 사람 영역. 회고는 임계값·교훈·필터만 대상.

### 3.1 🗃️ 기각 원장 — 재제안 방지 (2026-08-20 신설)

회고는 **같은 제안을 매주 다시 낸다**(반복 사례를 세는 구조라 근거가 계속 쌓인다). 백테스트로 기각된 제안은 여기 기록하고, 다시 올라오면 **표본 수를 비교해 기각**한다.

| 제안 | 회고 근거 | 검증 결과 | 판정 |
|---|---|---|---|
| **유동성 필터** — 후보 선정 시 거래대금 상위 우선 | 종결 2건 정성 관찰 (3주 연속: 06-15 · 07-01 · 08-01 · 34점) | **831건 백테스트에서 방향이 정반대** — 거래대금이 높을수록 성과 악화(돌파 100위내 기대값 **−1.04%** vs 전체 +0.68%), 눌림은 표본 소멸(381건 → 13건) | 🚫 **기각 (2026-08-20)** · 근거 `sop_테마발굴_보조지표.md` §4.2 · `backtest_exit_liquidity.py` |

> 💡 **이 건에서 얻은 교훈**: 회고의 관찰 자체는 틀리지 않았다. **「거래대금 100위 밖은 익절이 어렵다」는 룰 성과 문제가 아니라 얇은 판에서 사용자가 재량으로 조기 익절한 실행 문제**였고, 해법은 종목 필터가 아니라 **청산 룰**이었다(§4.4-D 절반 익절). → **회고 제안을 볼 때 "필터로 막을 문제인가, 룰로 정할 문제인가"를 먼저 가른다.**
>
> ⚠️ **정성 관찰 n건 vs 백테스트 n건**: 반복 횟수(3주 연속)는 신뢰도가 아니다. **같은 2건을 3번 센 것**이었다. 반복 카운트가 아니라 **독립 표본 수**로 판단할 것.
