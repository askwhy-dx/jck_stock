## 1. 돌파 정의 — 유형 1 (당일 폭발형, 확정 기준)

종가가 **112일선 또는 224일선**을 **그날** 상향돌파하면서, 그날의 움직임이 **폭발적**일 것:

| 조건 | 기준값 | 설명 |
|---|---|---|
| ① 라인 돌파 | 전일 종가 ≤ 선, **당일 종가 > 선** | 112선 또는 224선 (기본 OR, `--both`로 동시 강제) |
| ② 큰 양봉 | **당일 등락 ≥ +10%** | 한켐 5/22 = +19.4% |
| ③ 거래량 급증 | **당일 거래량 ≥ 20일평균 × 3배** | 한켐 5/22 ≈ 7배 |
| ④ 동전주/분할왜곡 제외 | 돌파일 종가 ≤ 기준선 +30% | 급등 후 선이 한참 아래인 가짜 제외 |

**중요 — 이건 무엇이 아닌가:**
- ❌ 이동평균선끼리의 교차(60일선이 112선 돌파 등)가 아님. **주가(캔들)**가 장기선을 뚫는 것.
- ❌ "선 위에 있는 상태"가 아님. **터지는 돌파 당일**만.
- ❌ 하락추세 페이드 제외: 쏘카(403550)처럼 급등 후 흘러내리며 약화된 선을 잠깐 닿는 건 거래량/양봉 조건에서 자연 탈락.

## 1-2. 돌파 정의 — 유형 2 (N일 전 돌파 + 현재 추세 유지)

유형 1의 돌파 정의(①~④)를 **기준일에서 정확히 N영업일 전(기본 N=3)** 하루에 적용해 돌파를 찾고, 거기에 다음을 추가:

| 추가 조건 | 기준값 | 설명 |
|---|---|---|
| ⑤ 추종 유지 | 돌파 후 N영업일 종가가 **돌파한 선 위 유지** | 선 아래로 되밀리면 탈락 |
| ⑥ 반납 금지 | **D+N 종가 ≥ 돌파일 종가** | 돌파분을 반납하면 탈락 |
| ⑦ 기준일 추세 건전 | 기준일 종가가 **112·224선 위 유지** | 라온로보틱스처럼 돌파 후 붕괴한 종목 제외 |

- ⑦의 **112선 상승 기울기** 조건은 통합 런너에서 **꺼둠**(`--slope-lookback 0`): 갓 N일 된 신선한 돌파는 장기 이평이 후행이라 아직 우상향 전환 전이기 때문. 오래된 돌파를 넓게 스캔할 땐 다시 켜면(예: `--slope-lookback 5`) 추세 붕괴주를 더 강하게 거른다.
- **왜 유형 1과 다른가**: 유형 1은 "오늘 막 터진" 신규, 유형 2는 "며칠 전 터져서 자리잡는 중인" 추종 확인용. window를 넓히면(`--window N`) 옛 돌파까지 섞이므로 통합 런너는 **window 1(그 하루)**로 고정.

## 2. 실행 방법

```powershell
# ── 통합 (권장) ──
python run_breakout_scan.py --date 20260608

# ── 유형 1 단독 ──
python screen_long_ma_breakout.py                     # 최신 캐시일 당일
python screen_long_ma_breakout.py --date 20260609     # 특정일 기준
python screen_long_ma_breakout.py --refresh --date 20260609  # KRX 갱신 후
python screen_long_ma_breakout.py --window 8          # 구간 스캔
python screen_long_ma_breakout.py --both              # 동시돌파만
python screen_long_ma_breakout.py --ret 15 --vmult 5  # 기준 강화

# ── 유형 2 단독 ──
python screen_ma_breakout_followthrough.py --date 20260608 --hold 3 --window 1 --slope-lookback 0
python screen_ma_breakout_followthrough.py --date 20260608 --hold 5            # 추종 5일
python screen_ma_breakout_followthrough.py --date 20260608 --window 20 --slope-lookback 5  # 옛 돌파 넓게+슬로프 ON
```

### 옵션 — 유형 1 (`screen_long_ma_breakout.py`)
| 옵션 | 기본 | 의미 |
|---|---|---|
| `--date YYYYMMDD` | 최신 캐시일 | 돌파 기준일 |
| `--window N` | 1 | 기준일 포함 스캔 영업일수 (1=당일만) |
| `--both` | off | 112·224 동시 돌파만 |
| `--ret` | 10 | 최소 당일 등락% |
| `--vmult` | 3 | 최소 거래량 배수(20일평균 대비) |
| `--maxgap` | 30 | 돌파일 종가-기준선 최대 이격%(동전주 제외) |
| `--refresh` | off | 스캔 전 KRX에서 최근 영업일 캐시 갱신 |

### 옵션 — 유형 2 (`screen_ma_breakout_followthrough.py`)
| 옵션 | 기본 | 의미 |
|---|---|---|
| `--date YYYYMMDD` | 최신 캐시일 | 추종검증 끝점(기준일) |
| `--hold N` | 3 | 돌파 후 추종/기준일까지 영업일수 (기준일 = 돌파일+N) |
| `--window N` | 20 | 돌파일 탐색 범위(통합 런너는 1로 고정) |
| `--slope-lookback N` | 5 | 112선 상승 기울기 판정 영업일 (0=끔, 통합 런너는 0) |
| `--both` `--ret` `--vmult` `--maxgap` | 유형1과 동일 | 돌파 정의 공통 옵션 |

### 옵션 — 통합 런너 (`run_breakout_scan.py`)
| 옵션 | 기본 | 의미 |
|---|---|---|

## 3. 데이터 주의사항
- 캐시: `data/krx_ohlcv_cache/` (KRX OpenAPI 일별 OHLCV). **2025-01-15부터 연속**(2024년치 없음) — 스크립트가 이 날짜부터 로드해 MA224를 정확히 계산. 그 이전을 섞으면 캐시 공백으로 MA가 왜곡됨.
